# Submission Checklist

Based directly on the competition brief.

- [ ] Team size is 1–3.
- [ ] Paper design is handwritten before coding: data structure + core logic.
- [ ] Photograph/scan of paper design is ready.
- [ ] `main.c` compiles cleanly with GCC.
- [ ] Core features demonstrated: insert, delete, display, save/load.
- [ ] Bonus features demonstrated: search, find/replace, undo, statistics.
- [ ] `HELP.md` documents every supported command with an example.
- [ ] `README.md` contains team members, features, compile and run instructions.
- [ ] Repository has a clean structure and meaningful commit history.
- [ ] Each team member has genuinely contributed; use real commit history/evidence.
- [ ] GitHub repository is pushed before the deadline.
